# Setup guide

This repo is the special GitHub profile repo: it must be named exactly like your username (`Anu7276/Anu7276`), be public, and contain `README.md`.

## 1. Publish
1. Copy everything in this folder into the repo root (keep `README.md`, `assets/`, `.github/`, `config/`).
2. Commit and push to `main`. The page appears on your profile.

## 2. Turn on the live 3D parts (one time)
The README references two images that GitHub generates for you:
- `profile-3d-contrib/profile-fire.svg` (3D contribution world, fire colours from `config/profile-3d-contrib.json`)
- `output` branch `snake-fire.svg` (contribution snake)

Open the **Actions** tab, enable workflows if asked, and run **"3D contribution world"** and **"Contribution snake"** once with *Run workflow*. After a minute the images appear; they refresh on a schedule after that.
If a workflow fails, open its log: the action versions in `.github/workflows` are the thing to check first (they were written from memory and not run before delivery).

## 3. Change the artwork or text
Everything in `assets/` is generated by the scripts in `tools/`:
```bash
pip install -r tools/requirements.txt
python -m playwright install chromium     # only needed for make_video.py / make_social.py
python tools/make_cutouts.py              # re-cuts tools/src/fire.png into shaded 3D-look characters (tools/src/cut2)
python tools/build_3d.py                  # rebuilds every SVG in assets/
python tools/make_social.py               # rebuilds assets/social-preview.png
python tools/make_video.py                # records a scroll-through demo video
```
- Characters: your source art is `tools/src/fire.png`. `make_cutouts.py` removes its background and bakes the lighting + thick edge into `tools/src/cut2/*.png`. New art with a different pose needs the clip-path coordinates in `tools/rig.py` adjusted; the rig animates head, hair, arm, tail, feet and eyelids.
- Colours: constants at the top of `tools/build_assets.py`.
- Text and numbers: functions in `tools/build_3d.py` (hero, stats, arena) and `README.md`.

## 4. Social preview (optional)
Repo **Settings > Social preview > Upload** `assets/social-preview.png`.
